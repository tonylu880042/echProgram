Echelon Program 客戶審閱規格
============================================================
文件狀態：Echelon 提案值／待客戶確認；不是已完成的產品行為。
Program ID：SUMMIT
正式名稱：SUMMIT
分類：CLIMB／漸進爬坡
Hero：是（第二層候選；idea.txt 第一列 launch lineup）
來源：idea.txt 第 20、16-30 行及第 247 行的 intelligence layer 描述。

一、客戶承諾與適用範圍
------------------------------------------------------------
客戶承諾：把一次「征服一座大山」的感受拆成逐段上升的爬坡體驗，讓使用者清楚知道下一個 climbing milestone。SUMMIT 不承諾真實戶外登頂能力或生理效益。
適合對象：能在低至中速下持續走／慢跑，且已確認可安全使用坡度的使用者。
不適合／前置條件：高坡度或長時間運動前要確認個人狀況與機台上限；若最大坡度未知，先以保守 cap 預覽，不可把 `15%+` 當成保證。

二、時長與運動型態
------------------------------------------------------------
Echelon 提案預設：30 分鐘。可選時長：20／30／45／60 分鐘。
運動型態：Progressive climb。
建議速度：2.5-4.5 mph（約 4.0-7.2 km/h）。
建議坡度：1-15%+。
建議強度：中等起步，逐步升至高；數值均為 Echelon 提案值，實作必須套用使用者 cap 與機台 limits clamp。

三、30 分鐘完整 Segment Profile（提案值）
------------------------------------------------------------
時間       區塊                 速度             坡度       UI coaching
00:00-05:00 BASE CAMP          2.6 mph/4.2 km/h  1%         FIND THE TRAIL
05:00-10:00 LOWER SLOPE         2.8 mph/4.5 km/h  4%         BUILD GRADUALLY
10:00-15:00 MID CLIMB           3.0 mph/4.8 km/h  7%         KEEP CLIMBING
15:00-20:00 UPPER CLIMB         3.1 mph/5.0 km/h 10%         STEADY POWER
20:00-25:00 SUMMIT PUSH         2.9 mph/4.7 km/h 13%         SEE THE SUMMIT
25:00-28:00 FINAL ASCENT        2.7 mph/4.3 km/h 15%         FINAL ASCENT
28:00-30:00 DESCENT / COOL DOWN 2.5 mph/4.0 km/h  2%         RECOVER
總和：5+5+5+5+5+3+2 = 30 分鐘，包含 warm-up 性質的 BASE CAMP 與 cool-down。

四、Echelon Adapt、EFFORT 與手動覆寫
------------------------------------------------------------
Echelon Adapt（提案）：依使用者 cap 把每個 ascent milestone 縮放；若某一坡度超出 cap，延長目前可用坡度區塊或以較低坡度完成，而不是跳過安全驗證。
EFFORT +/-（提案）：EFFORT + 只影響下一個尚未開始的 ascent 區塊；EFFORT - 優先降低坡度，再降低速度。冷身區塊不自動變重。
Manual override（提案）：當使用者改變值，將目前區塊標記 MANUAL；下一區塊提示是否恢復 Adapt。真實機台控制與命令確認尚未核准。

五、Live screen 必要欄位
------------------------------------------------------------
顯示 SUMMIT、目前／剩餘時間、speed／incline、climb milestone、profile chart、`NEXT: 13% SUMMIT PUSH`、countdown、EFFORT +/-、連線與資料新鮮度。若未接機台，顯示 `CLIMB PREVIEW` 並允許瀏覽 profile。

六、完成畫面與不得聲稱的內容
------------------------------------------------------------
顯示完成時間、距離、最高坡度、平均速度、裝置回報的估算 calories 與區塊完成率。不得聲稱完成真實山峰、提升登山能力、精準 calories 或個人最佳，除非有經核准的歷史比較。

七、安全與降級
------------------------------------------------------------
telemetry stale、設備不支援高坡度、控制未啟用或使用者到達 cap 時，凍結自動建議並提供降低坡度／結束入口。無 HR 時不做心率推斷。AIDL 控制只在 Gate3B 核准後可接通。

八、依賴能力
------------------------------------------------------------
Gate3A：唯讀速度／坡度／elapsed、連線／stale。Gate3B：speed／incline control 與 ACK。HR：非必要、尚未實作。History：可用於 Adapt／PR，但尚未實作。Generator：不需要。
